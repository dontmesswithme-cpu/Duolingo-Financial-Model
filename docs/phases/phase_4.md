### Task P4.1: WACC Build — CAPM with MKT-Labeled Market Inputs, As-Of Dates, Debt-Schedule Cost of Debt

#### A. Deliverable Files
- `src/engine/wacc.js` (new) — pure module implementing `build(input: WaccInput): WaccBuild` (spec §3.2 — FROZEN signature):
  - `WaccInput` shape (contract-defined): `{ assumptions, debtSchedule? }` — `assumptions` is the `AssumptionSet` from `loadAssumptions()` (or the output of `scenarios.apply`); `debtSchedule` is `schedules.build(...).debt` (optional; when absent the module resolves it from `assumptions` + the debt-free invariant). The build reads every market input via `requireDriverValue` (typed `EngineError('missing_driver', name)` on absent/non-finite) — no hardcoded market values anywhere in `src/engine/` (literal gate).
  - **CAPM build**: `cost_of_equity = rf + beta × ERP` with all three components as `MKT`-labeled drivers with mandatory `asOf: "YYYY-MM-DD"` and `source: { provider, url? }` in the driver record. Each driver carries `notes` stating the market source and access date (e.g. "10Y Treasury yield — FRED DGS10 — as of 2026-09-01") and the retrieval method is disclosed in the submission log. **Market inputs are never hand-typed without an `MKT` mark and an `asOf` date** — violation = FAIL.
  - **Cost of debt**: resolved from `debtSchedule.hasDebt` — Duolingo is debt-free per P2.3 (no borrowings metric matches `/borrow|notes payable|credit facility|term loan/i` in any cited balance). Therefore `cost_of_debt` is `null`/`0` with documentation, `weight_of_debt = 0`, and **`WACC = cost_of_equity`** (spec §3.2). The module must still implement the general WACC formula `WACC = (E/V)·Re + (D/V)·Rd·(1−t)` and prove it collapses to `Re` when `D = 0` — a hardcoded `WACC = Re` without the weight logic is a FAIL (the debt-free case is a theorem, not a branch that deletes the formula). Tax rate `t` is the normalized `effective_tax_rate` driver (P3.1 — `tax` group) read via `requireDriverValue`; the pre-tax cost of debt, when non-zero in a future corpus with debt, would be tax-affected by `(1−t)`.
  - **Capital weights**: `E = market_cap = share_price × shares_outstanding` (both `MKT` drivers with as-of dates), `D = 0` (debt-free), `V = E + D`. The build exposes the full weight table for the P5 Valuation tab: `{ riskFreeRate, beta, equityRiskPremium, costOfEquity, costOfDebt, taxRate, marketCap, equityWeight, debtWeight, wacc }`.
  - **Full build table**: the returned `WaccBuild` carries every intermediate (`riskFreeRate`, `beta`, `erp`, `costOfEquity`, `costOfDebt`, `taxRate`, `equityWeight`, `debtWeight`, `marketCap`, `wacc`) plus `isComputed: true`, `isEstimate: false` with `marking: "MKT"` on the market-sourced legs and `marking: "EST"` on the derived WACC where appropriate, `derivedFrom` chains into the driver citations, deeply frozen, deterministic.

Additive only; existing constants untouched.

### Task P4.2: DCF Valuation — Discount Factors, Explicit-Period PV, Gordon Terminal Value, EV → Net Cash → Equity → Per-Share Bridge

#### A. Deliverable Files
- `src/engine/dcf.js` (new) — pure module implementing `valuate(threeStatement: ThreeStatementOutput, wacc: WaccBuild, dcfInput: DcfInput): DcfResult` (spec §3.2 — FROZEN signature):
  - `DcfInput` shape (contract-defined): `{ assumptions, horizon? }` — `assumptions` supplies `terminal_growth_rate` (EST, via `requireDriverValue`), `shares_outstanding` (MKT, as-of dated), and optionally `market_share_price` for the bridge's market-cap cross-check; `horizon` defaults to `FORECAST_HORIZON_DEFAULT` (5 → FY2026–FY2030) and clamps to `[FORECAST_HORIZON_MIN, FORECAST_HORIZON_MAX]` (throws typed `EngineError('invalid_horizon', ...)` when out of range — same gate as `forecast.normalizeHorizon`). The FCF series is **not** passed in — it is read from `threeStatement.cashFlow.byPeriod[].free_cash_flow` (the `ThreeStatementOutput` shape frozen at P3.2 — DS must not re-derive FCF from a new formula; FCF = OCF + ICF identity already proven in P3.2).
  - **Discount factors**: per forecast year `t = 1..horizon` (FY2026 is `t=1`), `df_t = 1 / (1 + wacc)^t` with `wacc` from `WaccBuild.wacc`. Computed with `Number.isFinite` guards; division-by-zero / `wacc === -1` guard throws typed `EngineError('invalid_wacc', ...)`.
  - **Explicit-period PV**: `pvFcf_t = fcf_t × df_t` per year; `pvExplicit = Σ pvFcf_t` (FY2026–FY2030 inclusive; hybrid FY2026 FCF already carries the cited H1 `239,031` OCF anchor via P3.2 — no re-estimation). The full schedule `{ period, fcf, discountFactor, presentValue }` per year is exposed for the P5 Valuation tab.
  - **Gordon terminal value**: `terminalFcf = fcf_T × (1 + g)` where `fcf_T` is the final explicit year (FY2030) FCF and `g = terminal_growth_rate`. `terminalValue = terminalFcf / (wacc − g)` with **hard guard `wacc > g`** — violation throws typed `EngineError('terminal_growth_exceeds_wacc', 'Gordon terminal requires WACC > g')` (never silent, never clamped). `pvTerminal = terminalValue × df_T`. The terminal value is disclosed as of the final explicit year-end (standard Gordon convention — documented in `derivedFrom`).
  - **Enterprise value**: `ev = pvExplicit + pvTerminal`.
  - **Net cash bridge → equity → per-share**: Duolingo is debt-free per P2.3 — net cash = cash + short-term investments + long-term investments from the **final forecast balance sheet** (`threeStatement.balanceSheet.byPeriod[FY2030]` — the P3.2 `ending_cash` + held-constant `short_term_investments` + `long_term_investments` lines; all three are cited anchors from Q2 FY2026 with no forecast driver — the bridge must read them from the `ThreeStatementOutput`, never re-type them). `equityValue = ev + netCash` (no debt to subtract; the formula `equity = ev − debt + cash` is still exercised with `debt = 0` so a future levered corpus would not silently mis-bridge — same "theorem not branch" rule as P4.1). `perShare = equityValue / sharesOutstanding` where `sharesOutstanding` is the `MKT` driver with as-of date (fail-closed via `requireDriverValue`). All bridge legs carry `isComputed`/`isEstimate`/`marking` and `derivedFrom` chains into the balance-sheet lines and `WaccBuild`.
  - **Hybrid FY2026 honesty**: the DCF consumes the hybrid FY2026 FCF as built by P3.2 (H1 cited + H2 estimate) — it never rebuilds H1 from drivers. Under `scenarios.apply` (P4.3), H1 stays cited-actual and only H2 FCF responds to deltas (P3.3 ruling — carry-forward).
  - Purity: no DOM/fetch/`Date.now`/`Math.random`; deterministic; deeply frozen output.
- `tests/dcf.valuate.test.js` — DCF suite below.
- `tests/fixtures/duolingo_facts.js` (append) — DCF anchors derived at module load from the P3 outputs + market drivers per the `GROWTH_FIXTURE` pattern (e.g. `DISCOUNT_FACTOR_FY2026 = 1/(1+WACC)`, `PV_EXPLICIT`, `TERMINAL_VALUE`, `EV`, `NET_CASH = endingCash(FY2030) + STI + LTI`, `EQUITY`, `PER_SHARE`). Hand-typed DCF values are prohibited.
