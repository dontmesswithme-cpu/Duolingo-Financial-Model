> **Milestone**: Phase 5 — Interactive UI: 8-Tab Model Interface
> **Protocol**: 1.0
> **Status**: ⚪ Pending (Draft — awaiting Director approval; no amendments yet)
> **Owner**: Drafted & Audited by Reviewer (`OP`), Implemented by Worker (`DS`)
> **Objective**: Bind the verified valuation and projection engine (P4 — `412/412` green, `706` corpus, `wacc`/`dcf`/`recommend` + `scenarios`/`forecast`/`threeStatement`/`schedules` intact) into the Director-defined 8-tab static browser application (`index.html` + `src/app.js` + `src/ui/`): **Cover/TOC → Assumptions → Historicals → Schedules → Projections → Valuation → Summary → Sensitivity** with vendored Tabulator, driver-based blue-input controls, frozen label columns, `EST`/`MKT`/`computed` marking via `format.estSuffix`, custom SVG charts, and full-headless testability. ## 1. Milestone Objective & Scope

Phase 5 implements the presentation layer on the frozen P4 engine, per `docs/spec.md` `§3.3`–`§3.4` and `docs/plan.md` `§2` Phase 5: `P5.0` vendors the pinned Tabulator release (`vendor/tabulator/` + `docs/vendor/manifest.md` + SHA-256, OP audits manifest + integrity) and wires the ESM import; `P5.1` hardens engine fallback and gate coverage (see §3) so the UI never renders a masked literal; `P5.2` ships the app controller (`createApp` DI, clamped drivers, synchronous recalc `<16ms`, `dispose`) + tab-shell navigation + Cover/TOC (version from `git tag`, disclaimer, `EST`/`MKT` legend, TOC anchors); `P5.3` ships Assumptions (blue-input color-coding, schema-clamped controls) + Historicals (Tabulator `5Y+quarterly+TTM`, frozen label column + header, citation superscripts, source expansion, `computed` labels); `P5.4` ships Schedules + Projections (Tabulator grids with frozen labels across `10Y` column span, balance-check indicator, hybrid-year `H1`/`H2` split) + cell color-coding audit (`formatter` callbacks emit `cell-input`/`cell-formula`/`cell-link`); `P5.5` ships Valuation (WACC build table, DCF schedule, bridge waterfall) + Summary (mechanical `undervalued|fair|overvalued`, upside `%`, KPI cards, Rule of 40) + Sensitivity (data tables per `SensitivityInput`, scenario ranges); `P5.6` ships custom SVG charts (`revenue`/`FCF` actual-solid vs forecast-dashed, margin bars, DCF waterfall) + versioned screenshots `docs/screenshots/phase_5/v(n)/` for visual audit.

**Out of scope**: comps / precedent / LBO (excluded per `spec` `§7` — marked `N/A` on Cover/TOC only), any new corpus rows or any change to the frozen four-file `HISTORICAL_DATASETS` manifest (engine hardening is code-only: if DS believes a data gap blocks a contract item, FLAG for OP ruling — never transcribe unilaterally), any change to P4 valuation arithmetic (capsule-ward: `wacc`/`dcf`/`recommend` arithmetic stays byte-identical through `P5.1` except the removal of fallback literals), hypothetical debt issuance (`debt-free` handled explicitly per `spec` `§3.2`).
