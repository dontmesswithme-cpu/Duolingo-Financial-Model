# Design References

> **Purpose**: Store target visual benchmarks, Figma exports, UI wireframes, or architecture reference diagrams here.

## How to Use:
1. **For UI / Frontend Projects**: Place canonical UI mockups and design references here (e.g. `ref_login_screen.png`, `ref_dashboard.png`).
2. **For Architecture Projects**: Place architecture flowcharts or UML diagrams here (e.g. `system_architecture.png`).
3. **During Reviews**: Both Worker (`DS`) and Reviewer (`OP`) use files in this folder as the visual ground truth anchor for multimodal comparisons.
